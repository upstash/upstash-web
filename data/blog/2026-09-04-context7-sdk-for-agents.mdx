The Context7 SDK has been available for a while, but we never properly announced it. So here it is: [`@upstash/context7-sdk`](https://www.npmjs.com/package/@upstash/context7-sdk), a typed TypeScript client for giving AI agents direct access to current library documentation.

Context7 is commonly used through MCP. That works well when you want to add Context7 to an existing coding client. But if you're building the agent yourself, you often need more control over when documentation is retrieved, how it is returned, and what reaches the model.

The SDK is for that.

## Two Calls to Better Context

An agent first finds the right library, then asks for documentation using the user's actual question:

```bash
npm install @upstash/context7-sdk
```

```typescript
import { Context7 } from "@upstash/context7-sdk";

const context7 = new Context7({
  apiKey: process.env.CONTEXT7_API_KEY,
});

const question = "How do I revalidate a route in Next.js?";
const libraries = await context7.searchLibrary(question, "next.js");
const library = libraries[0];

if (!library) {
  throw new Error("Library not found");
}

const context = await context7.getContext(question, library.id, {
  type: "txt",
});

// Add `context` to your agent's prompt or tool result.
```

`searchLibrary` resolves a package to the right Context7 library. `getContext` returns documentation ranked for the question, including relevant code examples. Use plain text when the result goes directly to a model, or JSON when your application needs structured snippets and source metadata.

## Built for Agent Workflows

The SDK fits anywhere your application needs documentation programmatically:

- Coding agents that look up APIs before editing code
- Code generators that support fast-moving frameworks
- Documentation-aware support agents
- RAG and evaluation pipelines that need trusted library context

See complete examples for [Eve](https://github.com/upstash/context7/tree/a81a521389e2bfd9da4c8a1ec97996d76d22ce66/examples/eve), [Vercel AI SDK](https://github.com/upstash/context7/tree/a81a521389e2bfd9da4c8a1ec97996d76d22ce66/examples/ai-sdk), and [LangChain](https://github.com/upstash/context7/tree/a81a521389e2bfd9da4c8a1ec97996d76d22ce66/examples/langchain).
