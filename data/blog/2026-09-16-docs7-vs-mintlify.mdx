**Docs7 won 24 of 30 Google PageSpeed comparisons.** It led on 13 of 15 pages on mobile and 11 of 15 on desktop, using the median of three runs for each result.

{/* benchmark:lead:end */}

I submitted matching pages from our Upstash and Context7 docs to Google PageSpeed Insights, DebugBear, and Pingdom. I wanted more than a homepage comparison. The pages include image-heavy guides, long API references, a video, tabs, custom React components, Mermaid diagrams, and LaTeX.

Every performance number in this post comes from those hosted services. You can open the original reports from the tables below.

![Page comparisons won by Docs7 and Mintlify, grouped by testing service. Each row uses its own test conditions and sample size.](/blog/docs7-vs-mintlify/wins.svg)

## What we tested

{/* benchmark:test-date:start */}

The test date is **September 15, 2026**. We used the direct hosted URLs for each platform:

{/* benchmark:test-date:end */}

| Documentation | Docs7                                                                        | Mintlify                                                               |
| ------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Upstash       | [upstash-docs.docs7.io](https://upstash-docs.docs7.io/docs/introduction)     | [upstash.mintlify.dev](https://upstash.mintlify.dev/docs/introduction) |
| Context7      | [upstash-context7.docs7.io](https://upstash-context7.docs7.io/docs/overview) | [context7.mintlify.dev](https://context7.mintlify.dev/docs/overview)   |

We selected 16 page pairs. We excluded the SET command page from the comparison because Docs7 omitted the response value `OK`. Comparing a page with missing content would give it an unfair advantage. Its measurements remain in the download, marked as excluded.

- **Google:** three completed runs per URL on mobile and desktop, using the median for each page and device. These are [Lighthouse lab results](https://developers.google.com/speed/docs/insights/v5/about), measured by Google. The reports had no CrUX field data.
- **DebugBear:** one mobile run per URL, US East, 12 Mbps, 70 ms round-trip latency, and a medium device. Service errors stopped the tests after 10 completed pairs, so those are all included here.
- **Pingdom:** one matched run per host in the same city for each pair. The cities vary between pairs and are listed in the data. We repeated the Claim a library pair in Tokyo because its first two tests used different cities; only the matched repeat counts.

These tests measure the initial page load. We did not play videos or scroll through every image. We also left the deployed chat and analytics integrations in place. They did not behave identically across hosts, so these results compare the deployed sites, including their integrations. They do not isolate the rendering engine alone.

We also tried GTmetrix and WebPageTest. GTmetrix stopped at an account limit after three results. WebPageTest returned two results from different cities before its free limit. That was too little matched data for a useful comparison here. Both sets are included in the download.

[Download all third-party results, page URLs, and report links](/blog/docs7-vs-mintlify/results.json).

Docs7 leads across most of these pages, including pages with real components and media. If you are choosing where to host your docs, try the same test with your longest guide and your busiest API reference. A fast landing page is a start. The rest of the docs should keep up.
