**Docs7 won 13 of 16 Google PageSpeed comparisons.** In DebugBear, it led on 5 of 5 pages on mobile and 2 of 4 on desktop. In Pingdom, it loaded faster on 6 of 8 pages.

I tested documentation with images, video, long guides, code examples, and custom components on both platforms. The charts show the results; full tables and report links are at the end.

![Pages won in each test](/blog/docs7-vs-mintlify/wins.svg)

## The size of the gap

Across the tested pages, Google's median score was **64 vs. 53.5 on mobile** and **87 vs. 82 on desktop**. Pingdom's median load time was **659 ms vs. 733 ms**. Docs7 is listed first.

![Median scores and load times](/blog/docs7-vs-mintlify/typical-results.svg)

Google and DebugBear scores are out of 100; higher is better. Pingdom measures load time in milliseconds; lower is better.

## Why these pages?

I chose the pages before testing to cover different types of documentation.

- **Images.** Nine screenshots test image loading and layout stability.
- **Video.** An embedded player and a custom component catalog.
- **Guides.** A setup guide with tabs, steps, code, and five screenshots.
- **API references.** A long page with 36 code blocks and a short page with expandable fields.
- **Custom components.** Cards, code examples, and a React status badge.
- **Diagrams.** A Mermaid flowchart.

## How we tested

We compared **eight page pairs on September 16, 2026**, using the direct Docs7 and Mintlify hosted URLs.

- **Google PageSpeed Insights.** Three runs per URL on mobile and desktop, using the median score.
- **DebugBear.** One run per URL and device from US East. Each chart shows the number of completed pairs.
- **Pingdom.** One run per URL from San Francisco.

Charts show medians across pages or content groups. Each service uses its own test settings, so we keep their results separate.

These are [lab tests](https://developers.google.com/speed/docs/insights/v5/about) of initial page loads. Videos were not played. Chat and analytics stayed as deployed and differed between hosts. Cache state was not controlled, and scores vary between runs.
